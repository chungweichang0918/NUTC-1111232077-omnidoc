## 這套規則怎麼讓 AI 繼續做下去

`CLAUDE.md` 規定了：

1. **檔案放哪、怎麼命名**：`notes/<課程代號>/ch<兩位數章節>-<英文主題>.html`
2. **每篇筆記必備的 5 個區塊**與對應的 HTML 標籤／class（附可直接複製的範本頁）
3. **內容正確性規則**：以講義為準、補充要標註、選擇題要有四個選項、名詞定義不可套用
4. **新增筆記的標準流程與自我檢查清單**
5. **首頁卡片格式**：新增一張卡片，首頁的統計、課程篩選、搜尋就會自動更新

所以之後只要對 AI 說「依照 CLAUDE.md，用這份講義新增資料庫系統 CH4 的筆記」，AI 就知道要建立 `notes/database/ch04-….html`、套用同一套版面與結構，並把卡片掛到首頁。

## 本機 AI 筆記生成器（選用）

在本機打開 `index.html`，點「＋ 上傳 PDF / 圖片」，可以把講義交給自己架設的本機模型自動生成筆記。

- 模型：gemma3:12b（Ollama，執行於 Mac mini，透過 Tailscale 連線）
- 流程：讀取 PDF 文字 → 逐頁讀圖辨識（有快取）→ 依講義章節逐節撰寫 → 對照講義頁面補寫遺漏 → 自動修正格式
- 連線設定放在 `config.local.js`（不上傳）；公開網站是 https，無法連到本機 AI，生成器只在本機使用

其他功能：課程分類與搜尋、互動測驗與錯題本、名詞閃卡、對筆記提問、直接編輯、單節重新生成、筆記庫備份／還原。
